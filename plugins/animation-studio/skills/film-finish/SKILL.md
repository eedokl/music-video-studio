# film-finish

Input per section: `scenes/<section>/f.%04d.png` (any renderer – Synfig, Blender, three.js) and the song project
(`song-analysis`). All times are song seconds.

| Script | Does |
|---|---|
| `overlays.py <section> [--project .]` | `overlays/<section>.mov` (PNG with alpha): gags – words (`{"word", "text", "color", "place", "size"}`, pop with overshoot, tilted comic lettering) or pictures (`"icon"`: money, chip, kiss, heart, arrow_up, arrow_down, star, bolt; or `"image"`: an own PNG, optional word under it) – and, with `"lyrics": true`, the sung line at the bottom. `"lyrics_style"` per project or section: `script` / `caps` (word by word in a box) or `pop` / `rock` / `whisper` (letter by letter: each letter pops in as it is sung, held words stretch with the voice, the line kicks on the beat; trailing punctuation comes with the last letter). Per line: `"lyrics_lines": [{"line": prefix \| "contains": text \| "index": n, "style": name or dict}]`, `"lyrics_skip": [prefix or {"contains"/"index"}]` (project or section). Gags take `"sections"` / `"not_sections"`; two gags never share a place at the same time (a gag shown >= 0.5 s is replaced on its spot, else the later one moves to a free place). Word triggers everywhere: prefix, `"=exact"`, `"re:regex"`. Text never goes into scenes – camera moves crop it. |
| `sounds.py [project]` | `analysis/sounds.wav`: gestures and sound logs from `analysis/actions_*.json` (scene key clicks, toon-2d `breakout.py` climb/jump/landing/coins), a pop per gag, `"sounds"`: `{"word"}` / `{"at": s}` / `{"marker"}` / series `{"every": 0.85, "from": s, "to": s}` (heartbeat), each with `"sfx"`, `"level"`, `"pan"`, optional `"offset"` (s), `"dur"` (earshot `--dur`), `"sections"` / `"not_sections"`. Soft sounds ~9 dB under the music, 6 kHz low-pass, 10 ms fades. List of sounds: `earshot sfx list`. Skipped without earshot. |
| `build.py preview <section>` | section + overlays + song (+ sounds) + look → `preview/<section>.mp4` |
| `build.py film` | all sections frame-exact (gaps black), one continuous sound track, `title` (static fade by default; `"place"`/`"y"`, `"size"`, `"shadow"`, `"animation": "pop"` = overshoot pop-in, `"fade_out"`), `transitions` (see transitions.py), look once → `film.mp4`, `film_small.mp4` (< 30 MB), `film_mail.mp4` (~12 MB, 960×540 – mail adds ~33 %), each checked for decode errors |
| `popup.py [--draft]` | optional **pop-up video** version (like the 1980s "Pop-up Videos"): making-of cards pop up at free spots with a pop sound, held long enough to read → `film_popup.mp4` + `POPUPS.md`. `--draft` writes first cards from the project's ideas into `"popups"`; rewrite them into short, true facts about how *this* film was made (`{"at": s or "word": ..., "tag": "Rhubarb", "text": ..., "place": "auto"}`). Run after `build.py film`. With `"credits"` and `credits.mp4` also `film_popup_with_credits.mp4`; cards over the credits from `"popup_credits"` (`"at"` credits s \| `"segment": "post"` + `"at"` \| `"sound": "laugh.wav"` = when that sound plays, found by cross-correlation; `--no-credits` skips). |
| `credits.py [--draft [--gags N]] [--append] [--to s]` | **end credits** from project.json `"credits"`: one slowly rolling text cut into blocks, a short **gag** between two blocks (vocabulary: figure – bundled rig exported without mouth + drawn expression mouths, own PNG or a silhouette –, screen text, banner, speech bubble, prop / paper card, bang lettering, caption, desk, spotlight, zzz, counting chips, zoom, lights-out, or **any rendered clip / frame folder** e.g. a `figure_3d.py` morph), **scene windows** beside the text with seeded film excerpts (or explicit times) and **outtakes** (`outtakes/` or a list: rejected clips, stills, other seeds), music bed = instrumental (stems, else Demucs no_vocals with the GPU lock) at 0.22 under text / 0.6 in gags, soft sounds (earshot ids or files, 6 kHz low-pass, ~9 dB down), optional **post-credits** scene after black with an **audio-driven figure** (mouth + shoulders follow the loudness of a given audio file – use a real/user-provided laugh, TTS laughs sound bad) → `credits.mp4` with the look + `credits_sheet.png`; `--append` → `film_with_credits.mp4` (film.mp4 untouched). `--draft` writes the first text from the project (figures, song, the tools actually found per section, AI-content label, "Claudia by anabology" when she appears) and gag skeletons from the song's gag words/screen texts. Layout, excerpt picks and gag order follow the seed. Credits show film excerpts → `build.py film` rebuilds them when `"credits"` is set. Rebuild of the "Prompts!" credits: same 2073 frames and segment cuts, mean pixel difference 0.2–1.4 / 255. |
| `edit_handoff.py [--crossfade N]` | hand-off for manual editing: `film.otio` (Kdenlive 25.04+ / Resolve import; plain absolute media paths – Kdenlive fails on file:/// URLs) and `film.mlt` (with melt): section clips on V1, song + sounds on A1, exactly the film's timeline. Hard cuts by default (sections stay on their song frames); crossfades have no handles and shift later sections. Apply the look once after manual editing. |
| `cut.py cut.json [--version v2] [--out-dir D]` | **film cut WITHOUT a song timeline** (shorts, slide clips, dialogue scenes, explainers): shot list of stills (`frames`/`seconds`, optional slow `zoom`), paper title cards (`"card": "Title", "sub": ...`) and clips (`in`/`out`, own sound or a separate `audio` file, `gain_db`); transitions on the incoming shot: `dissolve` / `dip` / `whip` (two pictures, equal-power sound crossfade; `"handles": "auto"` = real handles when the clips have spare frames, else `overlap` = the film gets shorter like Kdenlive/MLT, or `hold` = outgoing last frame held, timeline fixed) or the frame-computed kinds of transitions.py; music bed (`"music": "m.wav"` or `{"score": {...}}` = score.py on the finished timeline) ducked under all shot sound, calibrated on the real local music level (default -4 dB free / -12 dB under speech, measured into `<out>_report.json`), mix at -16 LUFS (one gain + -2 dBFS limiter); `title`, `grade`, `letterbox`, look once; `versions` (values keyed by version names, e.g. `"transition": {"v1": "dissolve", "v2": "whip"}`) → `film[_v2].mp4`, `_small` (< 30 MB), `_mail` (~12 MB), decode check, `_sheet.png`, `_shots.json`, `.otio` (V1 shots + dissolves, A1/A2 shot sound, A3 `_music_bed.wav`), `.srt/.vtt` when shots carry `"subtitles"`. Tested: film_schnitt rebuild identical (713 frames, SSIM 0.99, levels ±0.2 dB, same OTIO), ai_efficiency v2 rebuild same length. |
| `score.py --plan cut.json [--seed N] [--style light\|orchestral]` | **film music for films without a song**: numpy synthesis that follows a cue list (`[{"at" \| "shot", "mood", "stinger"}]`, moods intro/playful/calm/night/tension/hope/sad/build/finale; from the shots' `"mood"` keys when no cues are given): e-piano/marimba/pluck lead, bass, shaker, bells, string pads; orchestral adds strings, brass swells and timpani; bars stretched to land on every cue, cue loudness evened out, final chord on the film end; the seed varies key, tempo, progressions, lead and accents. `--cues c.json --duration S` without a plan. **ElevenLabs Music** (opt-in): `--elevenlabs [--fetch]`, key only from env `ELEVENLABS_API_KEY` (never stored/printed); the prompt text (mood description) is sent to ElevenLabs and costs credits - ask the user first; cues cached in `cache/music_cues/`, laid on the cue list (same mood continues, loops at bar boundaries, last cue ends on the film end). |
| `subtitles.py --project . \| --dialogue analysis/dialogue.json \| --cut film_shots.json` | **SRT + VTT on film time** from a song project's `song_sheet.json` lines (minus the first section start), a talking-character `dialogue.json` (`--names` = "Tim: ..." / VTT voice tags) or the shots of a cut.py film; ≤ 2 lines × 42 characters, balanced breaks, long lines split at word times, ≥ 1 s and readable (17 chars/s), never overlapping (call-and-response lines are shortened); `--drop-calls` removes "(Prompts!)"; `--burn film.mp4` = burned-in copy `film_subtitled.mp4` (libass) for platforms without subtitle upload. |
| `second_audio.py --song other.wav --language en` | second audio language: the other song version stays unchanged and is shifted by ONE global offset found from the onset envelopes of both full songs (needs `source.path` in project.json; with an excerpt only it may lock onto another chorus) – the same sound effects mixed in → `film_en.mp4` with track 1 original (default) and track 2, language-tagged. Measured on "Prompts!" EN: 11 ms off the hand-made reference. numpy only (onset envelope = log-mel spectral flux, no librosa): `uv run --no-project --with numpy python second_audio.py ...` – same +9.044 s offset as the former librosa version. Re-cutting the song to fit the picture sounded chopped – don't. |
| `transitions.py` (used by build.py) | transitions computed frame by frame on the untouched cut (`cache/film_cut.mp4`), no handles needed: `zoom_through`, `glow`, `screen_zoom`, `iris` (numpy circle; `"shaders": true` = Shaders IrisWipe masks; `"hold_black": n` = closed n frames early, black up to the cut), `white`, `black` – `{"at": s, "kind": ..., "center": [x, y]}` |
| `apply_look.py video.mp4 [-o out] [--look standard\|<folder>] [--strength 0..1]` | the standard look on any video (overlay frames in `assets/look/standard`, JPG); `--look <name>` or a look folder made by shaders_render.py |
| `shaders_render.py look\|iris\|gallery\|catalog` (optional) | **makes** looks and transition masks with Shaders (npm `shaders` 4.0.6, WebGPU in headless Edge/Chrome, frame-exact): `look --preset p.json --name dream` → `assets/look/dream/` (24 JPG + look.json, ready for `apply_look.py --look dream`); `iris --out masks --center x,y --frames 12 --direction close\|open` → masks, and `iris_masks(center, frames, size)` = the mask provider for `"kind": "iris", "shaders": true` (numpy twin without GPU, max 1/255 difference); `gallery --image f.png --out gallery` → one frame through 16 effects + sheet for choosing; `catalog --out catalog`. The npm package is installed only with the user's OK (`--install` prints what it downloads). Guide: `references/shaders.md` |

Rules: write to temp files and rename (a player holding the old file must not break the build – the new file then
gets a new name); compute transitions from the untouched cut; never `-shortest` with the look; only one session
builds a project's film. `PREVIEW=1` → NVENC for work-in-progress files.
